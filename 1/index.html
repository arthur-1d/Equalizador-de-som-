Equalizador de Som com Arduino

Projeto escolar de robótica

Como funciona um equalizador?

Um equalizador de som é um equipamento que permite ajustar diferentes frequências de áudio. Essas frequências são divididas em três grupos principais: graves, médios e agudos. Com esses ajustes, é possível modificar o som de acordo com a preferência do usuário.

Nosso projeto

O projeto foi montado utilizando um Arduino UNO, um sensor de som KY-038, uma protoboard, LEDs, resistores e fios jumper.

A ideia era utilizar o sensor KY-038 para captar os sons do ambiente. O Arduino receberia o sinal do sensor e controlaria os LEDs, criando uma representação visual da intensidade sonora.

É importante destacar que o KY-038 detecta a presença e a intensidade do som, mas não separa as frequências em graves, médios e agudos como um equalizador convencional.

Componentes utilizados

  • Arduino UNO: controla o circuito.
  • Sensor KY-038: capta os sons do ambiente.
  • Protoboard: permite conectar os componentes.
  • LEDs e resistores: mostram a resposta visual do circuito.
  • Fios jumper: fazem as conexões.

Problema encontrado

O projeto não funcionou como esperado devido ao mau contato entre os pinos do sensor KY-038 e a protoboard. Essa falha na conexão dificultou a transmissão do sinal até o Arduino, impedindo o funcionamento correto dos LEDs.

Possíveis melhorias

  • Verificar se o sensor está bem encaixado na protoboard.
  • Conferir as conexões dos fios, da alimentação e do aterramento.
  • Testar o sensor separadamente antes de conectar os LEDs.

Conclusão

Mesmo não funcionando como planejado, o projeto permitiu aprender sobre sensores, circuitos e programação com Arduino. Também mostrou a importância de realizar conexões corretas e testar cada componente durante a montagem.
